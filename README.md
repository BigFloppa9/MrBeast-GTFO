# 🦁 MrBeast GTFO

**Тестовый кастомный бот для модерации Discord от мошеннических сообщений «Mr. Beast»**

Бот замечает аккаунт, который за несколько секунд рассылает одни и те же картинки по разным каналам, отправляет его в таймаут, удаляет его сообщения и пишет отчёт. Проект изначально сделан под **Termux**: бот и веб-панель управления работают прямо на вашем телефоне.

🌍 **Язык / Language:** Русский · [English](README_en.md)

---

## ✨ Возможности

- 🚨 Автоопределение: N картинок в M каналах за K секунд (по умолчанию 4 / 2 / 10)
- ⏱️ Таймаут нарушителю с понятной причиной в журнале аудита
- 🗑️ Удаление сообщений нарушителя за выбранный период по всем каналам
- 📋 Отчёты в канал логов и в веб-панель
- 🖥️ Тёмная веб-панель в стиле Discord: логи, статус, настройки серверов, языки
- 🔐 Вход по паролю, токен и пароль хранятся на устройстве в зашифрованном виде
- 🔑 Сброс пароля через Discord (привязанный аккаунт модератора)
- 🌐 Русский и английский: язык бота и язык панели настраиваются отдельно

## 📲 Установка на Termux

> Termux ставьте из **F-Droid** или **GitHub**, версия из Google Play устарела.

```bash
pkg update -y && pkg install -y git
git clone https://github.com/BigFloppa9/MrBeast-GTFO
cd MrBeast-GTFO
bash install.sh
```

Скрипт сам определяет, где он запущен (Termux, Docker или обычный Linux-сервер), и ставит всё нужное.

Запуск:

```bash
bash start.sh
```

В консоли появятся две ссылки:

```
http://192.168.x.x:8080   ← с любого устройства в вашей Wi-Fi сети
http://localhost:8080     ← с самого телефона
```

Откройте любую из них и пройдите первичную настройку. Если порт 8080 занят, бот возьмёт следующий свободный, актуальный адрес всегда печатается в консоли.

**Телефон выключился или Termux закрылся?** Откройте Termux и выполните:

```bash
cd MrBeast-GTFO && bash start.sh
```

**Обновление:**

```bash
cd MrBeast-GTFO && git pull
```

Затем перезапустите бота (`Ctrl+C` и снова `bash start.sh`).

### Docker и другие серверы

Запустите `install.sh` внутри контейнера или на сервере так же, как в Termux. В Docker откройте порт панели через `-p 8080:8080`. Порт, адрес и папку данных можно задать переменными окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MRBEAST_PORT` | `8080` | Первый порт для панели (если занят, берётся следующий) |
| `MRBEAST_HOST` | `0.0.0.0` | Адрес прослушивания (`127.0.0.1` оставит панель только для самого устройства) |
| `MRBEAST_DATA_DIR` | `./data` | Папка с настройками, логами и ключами |

## 🤖 Создание бота в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен. Он понадобится при первой настройке панели. Никому его не показывайте.
3. Там же, в **Privileged Gateway Intents**, включите:
   - **Server Members Intent**
   - **Message Content Intent**
4. Вкладка **OAuth2 → URL Generator**:
   - **Scopes:** `bot` и `applications.commands`
   - **Bot Permissions** (минимально необходимые, **обязательные**):

   | Право | Зачем |
   |---|---|
   | View Channels | видеть каналы |
   | Read Message History | находить сообщения нарушителя |
   | Manage Messages | удалять сообщения нарушителя |
   | Moderate Members | выдавать таймаут |
   | Send Messages | писать отчёты в канал логов |
   | Embed Links | отчёты отправляются как embed |

5. Откройте сгенерированную ссылку внизу страницы и добавьте бота на свой сервер.

⚠️ **Роль бота должна стоять выше ролей тех, кого он будет наказывать** (Настройки сервера → Роли). Администраторам и владельцу сервера Discord таймаут выдать не позволяет.

Если вы хотите, чтобы бот сам выдавал себе доступ к каналу логов, добавьте ему ещё **Manage Channels** (необязательно). Без него просто разрешите боту писать в канал логов вручную.

## 🖥️ Первый запуск панели

1. Откройте ссылку из консоли.
2. Вставьте **токен бота**, придумайте **пароль панели** (не короче 8 символов), выберите языки панели и бота.
3. Нажмите **Сохранить и запустить бота**. Токен проверяется в Discord перед сохранением.

> Завершите настройку сразу после запуска: пока она не пройдена, первый зашедший по ссылке станет владельцем панели. Панель работает по HTTP, используйте её только в доверенной сети.

### Разделы панели

| Раздел | Что внутри |
|---|---|
| **Логи** | Последние 300 действий в виде сообщений Discord: имя, юзернейм и ID нарушителя, текст триггера, ссылка на канал, картинки (одинаковые хранятся один раз), действие. Обновляются сами |
| **Статус** | Состояние бота, пинг, аптайм, список серверов |
| **Серверы** | Для каждого сервера: причина таймаута, длительность, период удаления, канал логов, пороги автоопределения |
| **Настройки** | Язык панели и бота, замена токена, привязка аккаунта модератора |

В логах панели поля нарушителя, текст триггера и названия обрезаются до 69 символов, чтобы спам не раздувал историю. Видео не сохраняются.

### Привязка аккаунта модератора и сброс пароля

Нужна, чтобы можно было восстановить пароль.

1. В панели: **Настройки → Аккаунт модератора → Сгенерировать код**.
2. Отправьте боту в **ЛИЧНЫЕ** сообщения команду `/reg КОД`. Аккаунт привязан.

Если забыли пароль:

1. На странице входа нажмите **Забыли пароль?**
2. Отправьте боту в **ЛИЧНЫЕ** сообщения команду `/log`. Бот ответит кодом только привязанному аккаунту.
3. Введите код в панели, затем новый пароль дважды.

Если аккаунт не был привязан, остановите панель, удалите файл `data/auth.json` и запустите снова: настройка пройдёт заново.

## ⌨️ Команды Discord

| Команда | Где | Права | Что делает |
|---|---|---|---|
| `/mrbeast <пользователь>` | сервер | Moderate Members | Таймаут и удаление сообщений вручную |
| `/mrbeastlog <канал>` | сервер | Administrator | Канал логов |
| `/mrbeastconfig` | сервер | Administrator | Причина, таймаут (`1d`, `12h`, `30m`, `1d12h`, максимум `28d`) и период удаления. Без параметров показывает текущие значения |
| `/reg <код>` | личные сообщения | любой | Привязка аккаунта модератора |
| `/log` | личные сообщения | привязанный аккаунт | Код для сброса пароля |

Всё, кроме `/mrbeast`, `/reg` и `/log`, можно сделать и в веб-панели.

## 🔐 Где что хранится

Всё лежит в папке `data/` (в git не попадает):

| Файл | Содержимое |
|---|---|
| `auth.json` | токен бота в зашифрованном виде и хэш пароля (PBKDF2-SHA256), сам пароль не хранится |
| `secret.key` | ключ шифрования токена |
| `settings.json` | настройки серверов |
| `config.json` | языки и привязанный аккаунт модератора |
| `logs.json`, `images/` | последние 300 логов и кэш картинок |

Токен шифруется (Fernet), ключ лежит отдельным файлом рядом, чтобы бот запускался сам после перезапуска. Это защищает от случайной утечки одного файла, но не от того, кто получил доступ ко всей папке `data/`. Не публикуйте её и не делитесь ей.

## 📱 Советы для Termux

- Отключите оптимизацию батареи для Termux, иначе Android может усыпить процесс.
- `start.sh` включает `termux-wake-lock`, чтобы телефон не усыплял процесс. Уведомление Termux лучше не закрывать.
- Телефон и устройство, с которого открываете панель, должны быть в одной сети.

## 🩺 Если что-то не работает

| Проблема | Решение |
|---|---|
| «Discord rejected this token» | Токен скопирован не полностью или сброшен. Получите новый в Developer Portal |
| Панель пишет про Intents | Включите **Server Members Intent** и **Message Content Intent** и перезапустите бота |
| Слэш-команд не видно | Подождите пару минут и перезапустите Discord. Бот должен быть добавлен со скоупом `applications.commands` |
| Таймаут не выдаётся | Роль бота ниже роли пользователя, или у пользователя права администратора |
| Нет отчёта в канале логов | Проверьте права бота в этом канале: View Channel, Send Messages, Embed Links |
